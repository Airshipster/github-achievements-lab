GitHub Discussions are used in this repository to collect public observations that do not fit cleanly into issues or pull requests.

## Rules

- Keep threads tied to observed behavior or reproducible questions.
- Do not create artificial accepted answers.
- Mark an answer only when it contains evidence, current documentation, or a reproducible result.
- Prefer adding findings back to `docs/findings.md` after an observation is confirmed.
